# Motivating Examples

This directory contains compact, curated examples for paper writing and manual inspection.

Each example should include:

- a short README explaining why the example is useful;
- original source files relevant to the migration;
- output source files or diffs from each compared approach;
- regression-test summaries;
- migration-integrity or anti-cheat evidence when available;
- a local viewer when useful.

Examples should be selected conservatively. Avoid cases where the migration could reasonably be attacked as invalid, test-specific, no-op, or only partially migrated.
